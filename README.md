# Açaí de Minas

Cardápio em React/TanStack Start adaptado do template fornecido.

- Produtos e categorias: src/data/menu.ts
- Contato e dados da loja: src/data/business.ts
- Estilos: src/styles.css
- Um produto por categoria, conforme escopo aprovado.
- Sem taxa de uso; entrega confirmada pela loja via WhatsApp.
- Arte principal ilustrativa; miniaturas extraídas visualmente dos prints fornecidos via CSS.

Use Bun com bun.lock. Build: bun run build. Vercel usa preset próprio quando VERCEL está definido.
